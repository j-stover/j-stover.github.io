Cal_Sync privacy policy

Last updated: November 18, 2026

Who uses this app

Cal_Sync is a personal tool used only by its owner, on the owner's own Mac. It is not offered to the public.

What Google data it accesses

With the owner's permission, Cal_Sync uses the Google Calendar API to read the owner's list of calendars and to read, create, change and delete events in the calendars the owner chooses to sync (scopes calendar.events and calendar.calendarlist.readonly).

How the data is used

Event details (title, time, location, notes, link, reminders, repeat rules) are used only to keep the owner's Google calendars and the owner's own Apple iCloud calendars the same. Nothing else is done with them.

Where the data is stored

Cal_Sync stores a sync database, short-lived backups and its sign-in token only on the owner's own Mac. There is no Cal_Sync server or cloud service, and no data is sent to the developer.

Sharing

Google user data is not sold, shared with, or transferred to anyone. It is copied only into the owner's own Apple iCloud calendar, as the owner asked. Short status alerts sent to the owner's private Discord channel contain no event details. Cal_Sync shows no ads and does not use the data for advertising, profiling or training of any model.

Cal_Sync's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove Cal_Sync's access at any time at myaccount.google.com/permissions, and delete its local files from their Mac.
